# Problem Statement

Bob is a fresher at MIT Manipal, and saw a Fancy Dress Competition going on at the Student Plaza where `n` contestants were standing in a circle.
Each person was holding a card with their score. The number on the card could be positive, negative, or zero.

Bob decided to find a continuous chain of people along the circle such that the sum of their scores is maximum.

Help Bob find the maximum sum possible.

# Input Format

- First line contains the size `n` of the array.
- The second line contains `n` space-separated integers representing the scores.

# Constraints

- `1 <= n <= 3 * 10^4`
- `-10^9 <= nums[i] <= 3 * 10^9`

# Output

Print the Maximum Sum possible.

# Examples

### Input 0

```
4
1 -2 3 -2
```

### Output 0

```
3
```

### Input 1

```
3
5 -3 5
```

### Output 1

```
10
```
