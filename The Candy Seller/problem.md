Divyansh is a professional dealer of speical _blue candies_. Today he encountered a weird customer, who gave him an array of size `n` with each index representing a certain amount of money.

He proposed a challenge for Divyansh that if he can find two indexes which sum up to the cost of the _special blue candies_ he would give him double the money, but if he failed Divyansh would have to give the candies to him for free.

He assured Divyansh that he can always find two such indexes.

Your goal is to help Divyansh find, two such indexes.

# Input Format

First line contains the size `n` of the array and the target value `t`
The second line contains `n` positive integers representing the cash at that index position `i`

# Constraints

- 2 <=`n` <= 10^4
- 0 <= nums[i] <= 10^5

# Output

Print the index `i` and `j` with space seperation where `i < j`

# Examples

### Input 0

```
5 9
2 7 11 15 5
```

### Output 0

```
1 2
```

### Input 1

```
2 2
1 1
```

### Output 1

```
1 2
```
