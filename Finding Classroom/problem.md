# Problem Statement

Abhishek D is a special person in MIT (a living Urban Legend), who has been in his first year three consecutive times, and this is his fourth time here. Apparently, the management has decided to change the AB3 classrooms from numbers to Roman Numerals, and he is having difficulty finding his class.

Help Abhishek convert his classroom number into Roman Numerals so he can find his classroom!

Roman numerals are represented by seven different symbols:

- `I` = 1
- `V` = 5
- `X` = 10
- `L` = 50
- `C` = 100
- `D` = 500
- `M` = 1000

Roman numerals are usually written largest to smallest from left to right. However, the numeral for 4 is not `IIII`. Instead, the number 4 is written as `IV` (one before five). The same principle applies to 9 (`IX`), 40 (`XL`), 90 (`XC`), 400 (`CD`), and 900 (`CM`).

# Input Format

A single line containing an integer `n` representing the classroom number.

# Constraints

- `1 <= n <= 3999`

# Output

Print the Roman numeral representation of the classroom number `n`.

# Examples

### Input 0

```
374
```

### Output 0

```
CCCLXXIV
```

### Input 1

```
58
```

### Output 1

```
LVIII
```

### Input 2

```
1994
```

### Output 2

```
MCMXCIV
```
