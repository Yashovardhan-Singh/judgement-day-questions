# 271A — Beautiful Year

**Difficulty:** Easy

## Problem Statement

Given a year y, find the smallest year strictly greater than y whose four digits are all distinct.

The answer is guaranteed to exist.

## Input

The input contains one integer y (1000 ≤ y ≤ 9000).

## Output

Print the smallest valid year strictly greater than y.

## Samples

### Sample 0

**Input**
```text
1987
```

**Output**
```text
2013
```

### Sample 1

**Input**
```text
2013
```

**Output**
```text
2014
```
