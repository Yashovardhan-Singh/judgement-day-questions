# 239A — Two Bags of Potatoes

**Difficulty:** Medium

## Problem Statement

A first bag originally contained x potatoes and a second bag contains y potatoes. The first bag was lost.

You know that x + y ≤ n and x + y is divisible by k. Determine every possible positive value of x in ascending order.

## Input

The input contains three integers y, k, n (1 ≤ y, k, n ≤ 10^9; n/k ≤ 10^5).

## Output

Print all possible values of x separated by spaces in ascending order. If no such value exists, print -1.

## Samples

### Sample 0

**Input**
```text
10 1 10
```

**Output**
```text
-1
```

### Sample 1

**Input**
```text
10 6 40
```

**Output**
```text
2 8 14 20 26
```
